# 5G_FEST

3D ピタゴラスイッチ（Pythagoras Switch / Rube Goldberg Machine）のサンプルリポジトリです。

## 概要

- **index.html** … トップページ
- **sample/** … 物理シミュレーションによる3Dピタゴラスイッチ

### sample の特徴

- **Three.js + Cannon.js** による本物の物理演算
- 重力・摩擦・反発を地球相当に設定
- 多段ギミック：
  1. スタート台からのボール落下
  2. 急傾斜レール（はらはら要素）
  3. シーソー（ヒンジ拘束）
  4. 第2ボール解放
  5. スパイラル風下降路
  6. ドミノ列
  7. 振り子ハンマー
  8. 最終レール → ゴール
- はらはら系の演出（落ちそうで落ちないレール、倒れ切るか不安なドミノなど）
- マウスで視点操作可能

## 使い方

1. リポジトリを clone するか、GitHub Pages で公開
2. `index.html` を開く
3. 「サンプルを開く」から `sample/` へ
4. 「スタート」ボタンを押すと連鎖が始まります

## 技術

- Three.js r128
- Cannon.js 0.6.2
- OrbitControls

物理法則に忠実に設計していますが、ブラウザの性能やタイミングによって完全な連鎖が保証されない場合があります。リセットして何度もお楽しみください。
