# 5G_FEST

3D ピタゴラスイッチ と 画面デコレーション用フルスクリーンアニメーションのリポジトリです。

## 構成

| パス | 内容 |
|------|------|
| `index.html` | トップページ |
| `sample/` | 3Dピタゴラスイッチ（物理演算） |
| `画面デコ/` | 天吊モニター向けフルスクリーンアニメ |

---

## sample/ — 3D ピタゴラスイッチ

- Three.js + Cannon.js による本物の物理演算
- 重力・摩擦・反発を地球相当に設定
- 多段ギミック：スタート台 → 急傾斜レール → シーソー → スパイラル → ドミノ → 振り子 → ゴール
- はらはら系演出付き

## 画面デコ/ — フルスクリーンアニメーション

暗闇の部屋で天吊モニターに映すことを想定した、画面いっぱいに広がるアニメーションです。

### ミラーボール風（3種）
天吊モニターで部屋を照らす用途向け。

1. **Mirror Ball 01** — クラシック回転ミラーボール + 光線
2. **Mirror Ball 02** — ファセット反射・きらめき粒子
3. **Mirror Ball 03** — ソフトグロー球体と光の筋

### オペラピンク 妖美（5種）
暗闇の中でオペラピンクの妖しい・美しいアニメーション。

1. **Opera Pink 01** — 流れるシルクの波動
2. **Opera Pink 02** — 脈打つエーテルの球
3. **Opera Pink 03** — 舞い散る花びら粒子
4. **Opera Pink 04** — 幾何学的に開く模様
5. **Opera Pink 05** — 体積光の光線と霞

すべて単体HTMLで動作します（外部依存なし・Canvas 2D）。
フルスクリーン表示推奨です。
